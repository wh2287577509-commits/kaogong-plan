# 考公计划网站

这是一个本地使用的考公记录网站。当前已实现作息记录模块，后续会继续扩展知识点盘点、统计回看等模块。

## 打开方式

直接用浏览器打开 `index.html`。

## 数据保存

当前数据自动保存在浏览器 `localStorage` 中。只要使用同一个浏览器、没有清理网站数据、文件路径不变，关闭网页再打开后记录仍会保留。

页面顶部提供 JSON 备份导出和导入入口，建议定期导出备份。

## 统计回看规则

月视图里的“工作日薄弱项”只统计已经记录过的工作日。每个作息项按下面规则计分：

- 完成 / 按时：1 分。
- 部分 / 延迟：0.5 分。
- 未完成 / 未选择：0 分。

系统会分别计算起床、早间学习、晚间轻学习、睡觉等作息项的平均分，平均分最低的项目就是当月的薄弱项。

月视图里的“睡眠评分”只统计已经填写了睡眠感受的日期。每日睡眠感受按下面规则计分：

- 睡得踏实：1 分。
- 多梦：0 分。
- 中途醒 / 醒来累：-1 分。

本月睡眠评分使用已填写睡眠感受日期的平均分，避免因为记录天数不同导致分数虚高或虚低。

## 目录结构

- `src/shared/`：通用日期和存储能力。
- `src/calendar/`：2026 工作日历、节假日和公司休假。
- `src/schedule/`：作息记录模块。
- `src/knowledge/`：知识点盘点模块占位。
- `assets/styles/`：基础、布局和模块样式。
